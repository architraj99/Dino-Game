# Dino-Game 


Dino Game is a fun endless runner browser game inspired by the classic offline Chrome dinosaur game. The player controls a dinosaur that jumps over moving cactus obstacles while trying to survive as long as possible and achieve a high score.

---

# Features

- Dino Game has smooth jump physics logic
- We get moving cactus obstacles to dodge at random time
- Game has collision detection system, which seems challanging at beginning intentionally
- Live score counter
- Speed increases over time to increase the fun
- Restart game button
- Animated clouds and background
- Endless gameplay!

---

# Tech Used

- HTML
- CSS
- Java

---

#NOTE

-The game actually feels harder initially because of slow speed and required perfect timing, gets easy with increasing speed
-Dino is moonwalking under the sun as a fun thing, its not a mistake or bug. Let Dino have fun!!

---

# How to Play

1. Click on the given link
2. Press the SPACEBAR key to jump
3. Avoid hitting cactus obstacles
4. Try to survive and score higher
